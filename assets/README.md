# assets

## Что нужно положить сюда

### `albert-portrait.jpg` — обязательный файл

Чёрно-белый вертикальный портрет Альберта (тот, что был приложен к брифу:
Альберт в чёрной рубашке, указывает пальцем в кадр).

Требования:

- пропорции близкие к **4:5** (например 1000×1250 или 1600×2000 px);
- формат JPEG, вес желательно до 300 КБ;
- **лицо и жест должны быть в верхней половине кадра** — в CSS задано
  `object-position: 50% 26%`, чтобы при обрезке на мобильном лицо не срезалось;
- обработка не нужна: обесцвечивание и лёгкий контраст добавляет CSS
  (`filter: grayscale(100%) contrast(1.06)`), исходник можно класть цветной;
- фото не ретушировать, не менять лицо, не прогонять через нейросеть.

Пока файла нет, на первом экране автоматически показывается аккуратная
заглушка с подписью — сайт не выглядит сломанным.

### `favicon.svg` — уже лежит, это плейсхолдер

Простой значок (силуэт автомобиля золотом на графите). Заменить на финальный
знак, когда он появится.

### `og-cover.jpg` — желательно добавить

Картинка для превью в мессенджерах, 1200×630 px. Сейчас в `index.html`
в `og:image` временно указан портрет. После публикации на домене нужно:

1. положить сюда `og-cover.jpg`;
2. в `index.html` заменить `content="assets/albert-portrait.jpg"` на
   абсолютный URL вида `https://ваш-домен/assets/og-cover.jpg`
   (соцсети не принимают относительные пути);
3. там же заменить `<link rel="canonical" href="https://example.com/">`
   на реальный адрес сайта.
