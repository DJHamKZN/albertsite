# Сайт инвестиционного предложения — Альберт Шакуров

Одностраничный статический сайт. Без сборки, без npm, без внешних библиотек.

> **Статус: черновик на согласование.** Часть данных намеренно заменена честными
> заглушками — см. [`CONTENT_TO_CONFIRM.md`](CONTENT_TO_CONFIRM.md).
> Не публиковать на боевой домен до проверки текстов юристом.

## Файлы

```
├── index.html              страница целиком
├── styles.css              стили (графит + молочный текст + приглушённое золото)
├── script.js               меню, появление блоков, FAQ-аккордеон, калькулятор
├── assets/
│   ├── favicon.svg         плейсхолдер значка
│   ├── albert-portrait.jpg ← НУЖНО ПОЛОЖИТЬ (см. assets/README.md)
│   └── README.md           требования к изображениям
├── CONTENT_TO_CONFIRM.md   что нужно подтвердить у Альберта и юриста
└── README.md               этот файл
```

## Как открыть

**Локально:** двойной клик по `index.html`. Всё работает офлайн —
внешних шрифтов, CDN и запросов в сеть нет.

**Локальный сервер** (если нужно проверить как на боевом домене):

```bash
git clone https://github.com/DJHamKZN/albertsite.git
cd albertsite
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Как показать заказчику онлайн (GitHub Pages)

Включается один раз, в два клика:

1. Открыть **Settings → Pages** в этом репозитории:
   https://github.com/DJHamKZN/albertsite/settings/pages
2. В разделе **Build and deployment** → **Source** выбрать `Deploy from a branch`.
3. Ниже: ветка `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу:
   **https://djhamkzn.github.io/albertsite/**

Дальше любой `git push` в `main` обновляет сайт автоматически.

## Другие варианты публикации

**Netlify / Vercel / Cloudflare Pages** — подключить этот репозиторий.
Build command не нужна, publish directory — корень.

**Свой хостинг** — загрузить файлы по FTP в корень домена.
Никакой настройки сервера не требуется.

### После публикации на домене обязательно

В `index.html`:

- заменить `<link rel="canonical" href="https://example.com/">` на реальный адрес;
- заменить `<meta property="og:image" content="assets/albert-portrait.jpg">` на
  **абсолютный** URL картинки превью (соцсети не понимают относительные пути).

## Что реализовано

- **Mobile-first**, корректно от 360 px до широких экранов, без горизонтальной прокрутки.
- **Sticky-header** с подсветкой активного раздела и мобильным меню (закрывается по Esc).
- **Плавная прокрутка** по якорям с учётом высоты шапки (`scroll-padding-top`).
- **FAQ-аккордеон** на `aria-expanded` / `aria-controls`; без JS все ответы просто видны.
- **Калькулятор сделки**: считает `продажа − покупка − ремонт − прочие расходы`,
  делит положительную прибыль 50/50, а на нуле и в минусе показывает предупреждение
  вместо выдуманной выплаты.
- **Доступность**: skip-link, семантические теги, видимый `:focus-visible`,
  контраст молочного текста на графите выше 4.5:1.
- **Анимации появления** через `IntersectionObserver`, полностью отключаются
  при `prefers-reduced-motion: reduce`.
- **SEO**: `title`, `description`, Open Graph, canonical, favicon,
  JSON-LD `Person` — **только на подтверждённых данных**.
- **Портрет**: `width`/`height` заданы, при отсутствии файла показывается
  аккуратная заглушка вместо «битой» картинки.

## Чего на сайте нет и почему

- **Формы заявки** — нет намеренно. Без backend она показывала бы фальшивое
  «заявка отправлена». Основной канал связи — Telegram.
- **Ставки 28% годовых и ежемесячных выплат** — не публикуются, чтобы не смешивать
  распределение фактической прибыли с процентной моделью.
- **Реквизитов, ИНН, ОГРН, адресов, отзывов, числа инвесторов** — ничего не выдумано.
  Везде стоят честные пометки «будет добавлено после юридической проверки».
- **Кнопки «Вложить сейчас»**, таймеров, счётчиков и искусственного дефицита.
